Add job list command handler in the `match &self.cli.command` block.

Implementation steps:

1. Parse optional status filter:
   - If provided, validate it's one of: "pending", "in_process", "complete", "failed"
   - Convert to JobStatus enum using match
   - If invalid status, return error listing valid options

2. Set defaults: limit=20, offset=0
   - Cap limit at 100 to prevent excessive queries

3. Create database pool using tokio runtime

4. Query jobs using JobRepository::list_jobs(status_filter, limit, offset)

5. Display results as a formatted table:
```
Jobs (showing {limit} of {total}):

ID                                    Type    Status      Created
------------------------------------  ------  ----------  -------------------
{job_id}  {type}  {status}  {created_at}
...

Use --offset to see more results
```

For table formatting, use simple printf-style formatting (no external table library for now):
- Truncate job ID to first 8 chars + "..." for display
- Format created_at as "YYYY-MM-DD HH:MM"
- Right-align status column to 10 chars
- Left-align type to 6 chars

6. If no jobs found, print "No jobs found" (or "No {status} jobs found" if filtered)

Wrap in #[cfg(feature = "db")] with appropriate fallback error.
