<task type="auto">
  <name>Task 2: Create memory monitoring module</name>
  <files>src/performance/memory_monitor.rs</files>
  <action>
Create src/performance/memory_monitor.rs with the following components:

1. MemoryPressure enum:
   ```rust
   #[derive(Debug, Clone, Copy, PartialEq, Eq)]
   pub enum MemoryPressure {
       Normal,      // Below soft limit
       Elevated,    // Above soft limit (30MB)
       High,        // Above 90% of hard limit (45MB)
       Critical,    // At or above hard limit (50MB)
   }
   ```

2. MemoryMonitor struct:
   ```rust
   pub struct MemoryMonitor {
       soft_limit_mb: usize,
       hard_limit_mb: usize,
       eviction_threshold_pct: f64,
       system: System,
       pid: Pid,
   }
   ```

3. Implementation:
   - `new(soft_limit_mb: usize, hard_limit_mb: usize, eviction_threshold_pct: f64) -> Self` - Initialize with sysinfo System and current process PID
   - `check_memory_pressure(&mut self) -> MemoryPressure` - Refresh system memory info, get current process RSS, compare against limits
   - `current_memory_mb(&mut self) -> usize` - Return current RSS in MB
   - `should_evict(&mut self) -> (bool, MemoryPressure)` - Returns (should_evict, pressure_level)

4. Memory calculation:
   - Use sysinfo::System::refresh_memory() and refresh_process_specifics()
   - Get process memory with system.process(pid).map(|p| p.memory()) 
   - Convert bytes to MB: memory_bytes / 1024 / 1024

5. Threshold logic:
   - Normal: current < soft_limit
   - Elevated: current >= soft_limit && current < hard_threshold
   - High: current >= hard_threshold && current < hard_limit
   - Critical: current >= hard_limit
   - Where hard_threshold = hard_limit * (eviction_threshold_pct / 100.0)

6. Default configuration constants:
   ```rust
   pub const DEFAULT_SOFT_LIMIT_MB: usize = 30;
   pub const DEFAULT_HARD_LIMIT_MB: usize = 50;
   pub const DEFAULT_EVICTION_THRESHOLD_PCT: f64 = 90.0;
   ```

Add appropriate imports:
```rust
use sysinfo::{ProcessExt, System, SystemExt, Pid, ProcessRefreshKind};
use tracing::{info, warn, error};
```
