  <name>Task 1: Create QueryJobHandler with payload parsing and data pre-loading</name>
  <files>src/jobs/handlers/query.rs</files>
  <action>
Create src/jobs/handlers/query.rs implementing QueryJobHandler following the LoadJobHandler pattern:

1. Define QueryJobPayload struct with fields:
   - query_name: String ("wedding", "project", or "travel")
   - start_date: String (YYYY-MM-DD format)
   - days: i64

2. Define QueryJobResult wrapper struct with common fields:
   - query_name: String
   - start_date: String
   - days: i64
   - total_results: usize
   - execution_time_ms: u64
   - results: JsonValue (the actual query results)

3. Create QueryJobHandler struct holding:
   - pool: Pool&lt;Postgres&gt;
   - loaded_days_repo: LoadedDaysRepository
   - registry: QueryTemplateRegistry

4. Implement parse_payload() method:
   - Extract query_name, start_date, days from job.payload
   - Validate query_name is in ["wedding", "project", "travel"]
   - Validate start_date is YYYY-MM-DD format
   - Validate days is 1-366
   - Return QueryJobPayload or JobError

5. Implement ensure_data_loaded() method:
   - Call loaded_days_repo.get_missing_dates(start_date, days)
   - If missing dates exist:
     - Create DatabasePool from self.pool
     - Create ChunkGenerator
     - For each missing date:
       - chunk_generator.generate_chunk(date)
       - chunk_generator.save_chunk_to_db(&chunk)
       - loaded_days_repo.mark_day_loaded(date, 1440, None)
   - Continue with partial failures (don't fail entire job for load issues)
   - Return JobResult&lt;()&gt;

6. Implement JobHandler trait:
   - job_type() returns JobType::Query
   - execute() orchestrates:
     - Parse payload
     - Ensure data is loaded (call ensure_data_loaded)
     - Get query template from registry
     - Execute query and get results
     - Wrap in QueryJobResult
     - Serialize to JSON and return

7. Add unit tests for:
   - QueryJobPayload serialization/deserialization
   - QueryJobResult serialization/deserialization
   - Payload validation (invalid query_name, bad date format, out-of-range days)

Use the same patterns as LoadJobHandler: async_trait, spawn_blocking if needed (JobExecutor already handles this), tracing for logs, structured error handling.
